# 论文知识库 使用说明

用一篇论文做一个本地小型知识库：把论文放进来，之后就能**用中文提问，得到中文回答和原文出处**。

---

## 一、这个文件夹里有什么

```
论文知识库\
├── papers\         ← 把要入库的论文 PDF 放这里（当前已放 1 篇）
├── db\             ← 向量数据库（137 条知识片段，已建好，别删）
├── .venv\          ← 运行环境（装好的依赖，别动）
├── config.py       ← 配置（模型、DeepSeek Key、切块参数）
├── ingest.py       ← 建库脚本（有新论文时运行）
├── query.py        ← 提问脚本（平时用它）
└── README.md       ← 本说明
```

## 二、日常怎么用（就一个操作：提问）

1. 打开命令提示符（按 `Win` + `R`，输入 `cmd` 回车）
2. 输入下面两行，回车：
   ```
   cd /d "D:\86180\OneDrive\桌面\论文知识库"
   .venv\Scripts\python.exe query.py
   ```
3. 出现提示后输入你的中文问题，回车 → 得到中文回答 + 出处 + 原文依据
4. 可以连续问；想退出输入 `exit` 回车

> 第一次提问会闪一下 `Loading weights` 进度条，是加载模型，几秒就好，不是卡住。

## 三、添加新论文（不常用）

1. 把新的 PDF 复制到 `papers\` 文件夹
2. 重新运行建库（第 1 步同上，命令换成）：
   ```
   .venv\Scripts\python.exe ingest.py
   ```
3. 看到"入库完成，共 N 条知识片段"即成功

## 四、常见问题

- **问中文能答中文吗？** 能。提问 → 本地检索 → DeepSeek 整理成中文回答。
- **答不出来 / 报错？** 检查网络；若提示余额不足，去 `platform.deepseek.com` 充值。
- **论文是扫描件？** 没问题，建库时会自动 OCR 识别文字。
- **想换提问范围？** 切块大小、返回片段数在 `config.py` 里调（一般不用动）。

## 五、注意事项

- `config.py` 里存着你的 **DeepSeek API Key**，这是私密凭证，别把这个文件发给别人。
- `db\` 和 `.venv\` 不要手动删，删了知识库或环境就没了。
- 桌面原论文没被改动，`papers\` 里是它的副本。
